# Bài tập 1 — Tự tìm và sửa lỗi CSS (KHÔNG dùng AI)

Trang khuyến mãi thiệp Tết đã sửa lỗi box model + position. Mở `index.html` để xem kết quả:
- Menu trên cùng sticky, luôn nằm trên ảnh hero
- Ảnh hero phủ kín khung, tiêu đề nằm chính giữa
- 3 thẻ sản phẩm 1 hàng ngang, nhãn "-20%" ở góc trên phải mỗi thẻ, ảnh + nội dung nằm gọn trong thẻ
- Nút "↑" cố định góc dưới phải màn hình

8 lỗi đã sửa (box-sizing, sticky top/z-index, hero relative, object-fit: cover, card relative, bỏ height cố định, ảnh thẻ, nút ↑ dùng bottom).
